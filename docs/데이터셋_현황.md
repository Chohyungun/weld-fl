## 이미지 데이터셋

### 검증 완료 — 다운로드 가능

**RIAWELC**

| 항목 | 내용 |
|---|---|
| 링크 | github.com/stefyste/RIAWELC |
| 규모 | 24,407장 / 224×224 8bit PNG |
| 모달 | X선 방사선 투과 |
| 클래스 | LP(용입부족) / PO(기공) / CR(균열) / ND(정상) |
| 형식 | RAR 분할 19파트, 총 468MB |
| 검증 | part01 실제 다운로드 확인 (RAR v5) |

받는 법: `part01.rar`을 압축 해제하면 나머지 18개가 자동 병합된다.

**인용 의무 2편**
- Totino, B., Spagnolo, F., Perri, S. (2022) RIAWELC: A Novel Dataset of Radiographic Images for Automatic Weld Defects Classification, ICMECE 2022, Barcelona
- Perri, S., Spagnolo, F., Frustaci, F., Corsonello, P., Welding Defects Classification Through a Convolutional Neural Network, Manufacturing Letters

**미확인**: 바운딩박스 유무. 분류 라벨 기반으로 보이므로 YOLO 학습에 쓰려면
어노테이션 형식을 먼저 확인해야 한다.

**주의**: X선이다. 焊接学报(2026) 리뷰가 내부 결함(X선/초음파)을 VLM 증거등급 B/C류로
분류했으며, "X선 심층 검출을 독자적으로 담당할 VLM 단독 방안은 아직 없다"고 명시했다.

| 항목 | 내용 |
|---|---|
| 규모 | 약 30,000장 |

검색어: `Bacioiu welding`, `TIG aluminium HDR`

### 신청·회신 대기

**Intel Robotic Welding Multimodal**

| 항목 | 내용 |
|---|---|
| 링크 | huggingface.co/datasets/IntelLabs/Intel_Robotic_Welding_Multimodal_Dataset |
| 규모 | 4,000+ 샘플, 결함 12종 |
| 모달 | 비디오 + 오디오 + 센서 시계열 + 용접 후 이미지 5장 |
| 메타데이터 | STEEL_TYPE, THICKNESS_MM, WELD_TYPE, CURRENT_A, VOLTAGE_V, GAS_BAR, ROBOT_SPEED_CPM |
| 접근 | gated: manual (수동 승인) |
| 라이선스 | Intel Research Use License, 비상업 한정 |
| 지표 | 다운로드 61회, 좋아요 42 |

**익명 신청은 거부된다.** 기관 메일과 소속을 명시해야 한다.
인용 의무: Stemmer, G. et al. (2024) Unsupervised Welding Defect Detection Using Audio And Video, arXiv:2409.02290

메타데이터에 이질성 축(강종·두께·용접방식)이 내장돼 있어 연합학습 분할 설계에 유리하다.

**MWDD (WeldLLM 논문 데이터셋)**

| 항목 | 내용 |
|---|---|
| 링크 | zenodo.org/records/19563753 |
| 상태 | **Restricted.** 파일 목록 비어 있음, files API 403, 다운로드 0회 |
| 라이선스 | CC BY 4.0으로 표기돼 있으나 파일 잠김 |
| 클래스 | 7종 (가시광) |
| 조치 | 저자에게 메일 발송, 회신 대기 (연락처는 비공개) |

```
Bad Welding / Good Welding / Crack / Porosity /
Spatters / Welding Line / Excess Reinforcement
```

클래스 매핑은 `github.com/ucassqs/WeldLLM`의 `llm/src/datasets.py`에서 확인했다.

**원본 출처 추적 결과: 실패.** 세 곳을 확인했으나 전부 클래스 불일치.
코드에 `process_merged_dataset_annotations` 함수가 있어 병합본으로 추정되며,
원본 하나를 특정하는 것이 불가능할 수 있다.

## 코퍼스 원문 후보 (8/16 결정 방향)

이미지가 아닌 **텍스트 코퍼스 구축용 원문**이다.
QA로 가공된 것이 아니라 원문에서 시작해야 정보 손실과 오류 증폭이 없다.

## 코드 자산

**github.com/ucassqs/WeldLLM (MIT 라이선스)**

데이터 없이도 활용 가능하다. 표준 YOLO 폴더 구조(train/val/test, images/labels)만 있으면
동작하므로 클래스 매핑만 바꾸면 다른 데이터셋에 적용된다.

| 파일 | 내용 |
|---|---|
| `WTDWRyolo/.../WTDWR.yaml` | 논문의 검출망 구조 정의 |
| `llm/src/datasets.py` (113KB) | 어노테이션 생성기. 150+ 템플릿, 10섹션 분석 구조 |
| `llm/src/yolo_qwen_alignment.py` | YOLO-Qwen 정렬 모듈 |
| `llm/src/training_v1.py` | 정렬 학습 |

**설정값**

```
LoRA        r=16, alpha=32, dropout=0.1
1단계 YOLO  epochs 100, batch 32, imgsz 640, SGD
2단계 정렬  Qwen2.5-VL-3B, batch 1, epochs 3, lr 1e-4
추론        temperature 0.7, top_p 0.9
요구 사양   GPU 24GB 이상
```

**주의**: `datasets.py`가 생성하는 텍스트는 규칙 기반 자동 생성물이다.
바운딩박스 정보를 템플릿에 채워 넣는 방식이며, 실제 검사원이 작성한 것이 아니다.
논문은 "expert-level"이라 표현했으나 실질은 템플릿 채우기다.
평가 설계 시 이 한계를 반영해야 한다.
